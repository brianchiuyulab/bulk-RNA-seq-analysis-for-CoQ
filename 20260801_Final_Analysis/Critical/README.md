# Critical RNA-seq outputs

- `01_RNA_PCA`: global PCA using the 1,000 genes with the highest variance.
- `03_all_selected_genes_heatmap`: expression heatmap of 1,498 selected genes.
- `03_KEGG_top_pathways`: KEGG results for higher and lower Middle/Late-versus-Early signatures.
- `02_selected_consistent_direction_genes.csv`: complete selected-gene table.
- `02_differential_analysis_summary.csv`: analysis thresholds and result counts.
- `03_KEGG_top_pathways.csv`: plotted KEGG pathways and statistics.
